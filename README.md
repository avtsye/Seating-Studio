# Seating Studio

מערכת חדשה לניהול ותכנון שיבוץ מקומות באולם.

## מטרת הפרויקט
ממשק RTL מודרני שבו מפת האולם היא מרכז העבודה: בניית אולם, ניהול אנשים, שיבוץ אוטומטי וידני, חיפוש, סינון ותצוגת תוצאות — ללא מעבר בין מפות שונות.

## עקרונות
- מקור אמת יחיד למפת האולם ולשיבוצים
- תמיכה בגושים, שורות, מעברים ואזורים לא-מלבניים
- זום, גרירה והתאמה למסך
- פאנל צד תלוי-הקשר
- שיבוץ ידני ואוטומטי
- הפרדה בין מנוע הנתונים/השיבוץ לבין ממשק המשתמש
- בדיקות אוטומטיות לפעולות אמיתיות

## סטטוס
הדור החדש נמצא בהקמה.
